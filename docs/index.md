# moosey-cms Documentation

A lightweight, Jinja2-powered static site generator for Python.

## Reading Order

New to moosey-cms? Start here:

1. **[Getting Started](getting-started.md)** — Installation, configuration, and your first page.
2. **[Filters Reference](filters.md)** — All built-in Jinja2 filters for dates, text, numbers, HTML, and more.
3. **[Markdown Rendering](markdown.md)** — Using `markdown` and `markdown_inline` filters.
4. **[Image Processing](images.md)** — Automatic image resizing, responsive `srcset`, face detection, CDN support.
5. **[Templates](templates.md)** — Template syntax, static files, pagination, RSS, sitemaps, collections, and custom pages.
6. **[Security](security.md)** — HTML sanitization, Content Security Policy, sandboxing.
7. **[Patterns](patterns.md)** — Real-world project structures and conventions.
8. **[SEO](seo.md)** — Meta tags, Open Graph, structured data, robots.txt, canonical URLs.

> **Note:** The image and markdown filters require optional dependencies.
> See [Getting Started → Installing Extras](getting-started.md#installing-extras) for details.
